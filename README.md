# Farm-Management-System
Farm Management System Project

## Project Description
Farm Management System is a Salesforce-based application designed to manage farm activities, farmers, crops, and agricultural information efficiently.

## Objectives
- Manage farmer information
- Manage crop details
- Track farm activities
- Maintain agricultural records
- Improve farm management efficiency

## Technologies Used
- Salesforce
- Salesforce Developer Org
- Lightning App
- Custom Objects
- Custom Fields
- Relationships

## Project Phases
1. Project Planning
2. Requirement Analysis
3. Brainstorming
4. Customer Journey Map
5. Data Flow Diagram
6. Project Development
7. Testing
8. Project Documentation
